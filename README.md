# Portfolio Website - Elias Mashia

A modern, responsive portfolio website built with React, Vite, and Material-UI showcasing my skills, projects, and professional experience as a Software Developer.

## 🚀 Live Demo

Visit the live portfolio: [https://trans25.github.io/portfolio-website/](https://trans25.github.io/portfolio-website/)

## 🛠️ Built With

- **React** - Frontend framework
- **Vite** - Build tool and development server
- **Material-UI** - Component library
- **Framer Motion** - Animation library
- **EmailJS** - Contact form functionality
- **GitHub Pages** - Hosting

## 📋 Features

- Modern and responsive design
- Smooth animations and transitions
- Interactive sections: About, Skills, Projects, Certifications
- Contact form with email integration
- Downloadable CV
- WhatsApp integration for direct contact
- SEO optimized

## 🏃‍♂️ Running Locally

1. Clone the repository:
```bash
git clone https://github.com/trans25/portfolio-website.git
cd portfolio-website
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## 📦 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run deploy` - Deploy to GitHub Pages
